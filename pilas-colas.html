Un solo concepto nuevo

Pilas y colas guardan cosas en orden, con una regla para sacar.

Pila

Sale el último que entró.

Cola

Sale el primero que entró.

Primero lo vemos en la vida real. Después, en Python.

Paso 2 · Ahora en Python

La pila en Python

Código
historial = []
historial.append("escribir hola")  # apilar
historial.append("poner negritas")
historial.append("borrar palabra")
print(historial[-1])     # ver la de arriba
print(historial.pop())   # sacar la de arriba
print(historial)
print(len(historial) == 0)  # ¿está vacía?

borrar palabra
borrar palabra
['escribir hola', 'poner negritas']
False

La cola en Python

Código
fila = []

fila.append("Luis")
fila.append("Sofía")

print(fila)
print(len(fila) == 0)  # ¿está vacía?
Salida
Ana
Ana
['Luis', 'Sofía']
False

[0] mira al primero sin quitarlo · pop(0) lo quita y lo regresa · el 0 es la posición del primero

Misma lista, distinto pop

¿Para qué sirve?

Dónde vive en la tecnología

Pila

El Traceback de Python. Cuando una función llama a otra, Python las apila para saber a dónde regresar. Por eso el error dice «most recent call last».

Deshacer y «atrás». Word, Photoshop y el navegador guardan tus pasos en una pila.

Cola

La fila de reproducción. «Agregar a la fila» en Spotify o YouTube: suena primero lo que agregaste primero.

Un servidor web. Cuando miles entran a una página, el servidor atiende las peticiones en orden de llegada.

En tu carrera

¿Y en ciberseguridad?

Cola

Denegación de servicio

Un atacante manda miles de peticiones falsas para llenar la fila del servidor. Los usuarios reales ya no alcanzan turno.

Es como formar 500 clientes falsos en la tortillería. Defensa: limitar cuántas peticiones hace cada quien por minuto.

Pila

Desbordamiento de pila

En lenguajes como C, si un programa escribe más datos de los que caben, puede pisar el dato que dice a dónde regresar.

Un atacante lo aprovecha para cambiar a dónde salta el programa. Es una de las fallas más antiguas y famosas.
